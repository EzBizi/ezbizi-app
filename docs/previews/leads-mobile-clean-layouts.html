Leads on a phone: cleaner and simpler

From a staff message (paraphrased): the reply box is too small, the top should scroll away so the messages show, and replying is hard. Jose: "mobile is a mess, we need something cleaner and simpler". What's wrong today:

  • Thread: the header, Status and Book use about 40% of the screen. Once the keyboard opens, no messages show at all, and the reply box is a 3-line square squeezed beside Suggest, emoji and Send.
  • List: filters use half the screen (sources, 4 quick chips, More filters, 3 rows of channels) before the first lead, and each row truncates its pills.

Each option is drawn twice: the thread with the keyboard up, then the list. Desktop doesn't change.

1 Messenger style: one-line header, full-width composer, one Filters button RECOMMENDED

  • Header: one app-bar row (back, avatar, name, a status chip that opens the status picker in a sheet, Book, ⋯). Job, phone, notes and More go into ⋯ (a sheet).
  • Messages fill everything between the header and the composer, even with the keyboard up.
  • Composer: full width, pinned above the keyboard, and grows from 1 to 5 lines as you type. + on the left opens quick replies, Suggest, emoji and Attach; a round Send is on the right. Quick replies show as one chip row only while the box is focused and empty.
  • List: search plus one "Filters (3)" button. Sources, channels and the quick chips move into its sheet, and only the quick chips you picked stay on screen as one row. Each row is two lines: name and time; then pills and the last message.
