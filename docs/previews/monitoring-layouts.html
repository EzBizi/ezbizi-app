Monitoring — PC Specs, three layouts

Same tab, same data, three ways to read it. Answer by number.

Real palette from theme.dart, real field data (A‑1 Chimney + Everdoors). The rule the whole tab turns on: a device shows only what it can report — a web session gives you tab + dwell + last seen and nothing more, and the layout says so out loud rather than leaving a blank that reads like a bug. Specs (RAM/disk/wifi/open apps) exist only where the desktop agent is installed. Resize the window narrow to see the 375px behaviour.
