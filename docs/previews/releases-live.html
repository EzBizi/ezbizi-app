Development › Releases · live view

Three ways to show a running release: time left (remaining stages at their median past duration), the live gate log, and what ships in it (notes plus merged commits). All three add a Superseded state for runs a later release overtook, which fixes the stuck "No word for 3 hours" row. Figures are from v0.0.0564. Releases also becomes the default tab when Development opens (Jose).

A · Countdown, stages and what ships RECOMMENDED

Large "time left" figure with a finish time. Every stage shows how long it took (or its median when still to come), with the live log under it and the release notes beside it. On phone it stacks.

B · CI pipeline with tabs

GitHub Actions / Vercel style: one box per stage in a row, then tabs for the log, notes and commits. Shows every native build separately.

C · Compact with one live line

Today's card plus time left and the latest log line ticking under the bar. Notes and full log fold away.
