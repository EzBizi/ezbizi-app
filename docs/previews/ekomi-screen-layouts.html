Customer Experience › eKomi: a screen of its own

Today eKomi is one "Connected" row under Review links › Sources. This adds what A1 Tools had: an account snapshot, the request funnel, who was asked, the eKomi reviews, and automatic requests when a job is Done. It also adds one thing A1 Tools didn't have: sending a request from a job by hand. It opens in place from that Sources row, with a back arrow (no pushed screen). Every name and number is invented.

1 Four tabs: Overview · Requests · Reviews · Settings RECOMMENDED

  • Top: ← back, "eKomi · Brightside", a Connected chip, the shared date bar (Last 30 days) and the certificate link.
  • Overview: four tiles (reviews, average, requests sent, review rate). Under them, the funnel as bars from Requested to Reviewed, each with its rate, and Bounced in red.
  • Requests: a search bar (name, email, job), Status and Channel chips, one row per person asked, and "Send review request" (pick a job; one request per job).
  • Reviews: the Reviews list you already have, filtered to eKomi, so it isn't a second list. Settings: shop id, password (left blank keeps it), on/off, Test connection, and Automatic requests (on/off, delay in hours, only jobs Done after a date).

2 One page, no tabs: overview, then requests, with settings in a side panel

The snapshot and a short funnel sit at the top and the requests table is underneath. A "Settings" button opens a side panel. Everything is on one scroll and nothing is hidden behind a tab, but the reviews aren't here: you open them from Reviews.
