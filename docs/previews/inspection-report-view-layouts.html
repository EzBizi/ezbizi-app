203 · Inspection › Generated Reports: the report reads like the PDF

Jose (11-23, via the desk): the report in the app "should be more similar" to the PDF, with groups and colours. Today the app prints every answer as one flat list of grey label/value rows, including the steering questions the PDF hides. All three options below draw the same report the PDF prints: only the questions this inspection actually asked, the steering ones left out, each finding as a card with a green / red / grey bar and a PASS / FAIL / N/A badge, the chosen words under it, the code it's measured against in a quote block, and its photos, notes and work underneath. The result line ("Fail · 2 of 14 items did not meet standards") sits on top. Nothing on the server changes. The report stays frozen, as before.

1 · The PDF's page, as section cards (recommended)

A result banner on top with the Pass / Fail / N/A counts. Then one card per section, the way the PDF has a heading per section. Plain answers (client, address, chimney type) sit in a 3-column grid inside the card, not one per line. Findings are bar-and-badge cards, with failures tinted red. The "Inspection summary" table from the PDF's last page closes the report. Download PDF and Archive stay at the bottom.
