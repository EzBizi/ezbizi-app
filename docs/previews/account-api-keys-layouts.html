Your account · API keys

From the MCP / API session, for Jose's ask of 2026-10-06: "build the MCP and API so AIs can manage operations natively". An API key lets an AI (Claude, for one) or a script work in EzBizi as you, with your permissions and nothing more. You name the key, choose Read only or Can make changes, copy it once, and can revoke it at any time.

Data: GET /me/api-keys lists them (name, access, last used, made), POST makes one and returns the key once, since it can never be read back, and DELETE revokes it. The server is on the MCP session's branch and not on main yet. Keys stop being listed under "Where you are signed in". In every option: the key is shown on the page until you say you have copied it, so no stray click can lose it. Copy buttons for the key and for the Claude Code setup line. Revoking is confirmed in place, never in a dialog. The safer choice, Read only, comes selected.

1A card under "Where you are signed in": make, copy and revoke in the card Recommended

The keys are listed like the sign-ins above them. New API key opens a short form in the card: a name and two side-by-side choices. Once it's made, an amber box at the top of the card holds the key and the setup line, each with Copy, until you press Done. Why: everything happens where the list is, there is no layer to dismiss by accident while the key is showing, and the page looks like the rest of Your account.
