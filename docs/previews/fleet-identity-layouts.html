Already decided, not in this gallery The card edits in place — every field is a live control, enabled when the signed-in role holds fleet_management.edit and disabled otherwise, one Save on the card, no separate view mode. So read-only density tricks are not available. Body type, Fuel type and Status are dropdowns; Company and Franchise appear only when the current view leaves a real choice. No modals; colours from theme.dart; 375px is a floor.
The measured facts these are designed against — 21 fields across A-1's 24 real vehicles Fill rates: always (24/24) year · make · model · plate_state · vin · body_type · fuel_type · status  ·  22 colour  ·  16 odometer + its date  ·  9 plate  ·  3–4 toll device · toll plan · registration expiry  ·  0 trim · next service date · next service miles · inspection expiry · toll flat rate · notes. 1 · The finding, and it is not a layout problem. plate_state is 24/24 while plate is 9/24 — the import correctly nulled eleven typed absences ("NA", "(NEW)"). So fifteen vehicles render "Plate state: CT" beside an empty Plate. Two fields, one fact, and the always-present half is the useless half. Every layout here draws them as one control: a state selector attached to a plate field, so "CT / —" reads as one incomplete fact. 2 · Six fields are empty across the entire fleet, and hiding them is not allowed. An editable field that hides when empty can never be filled. So no layout hides anything by data — where fields are folded away, the user opens the fold, and it stays open. 3 · toll_flat_rate_cents is in the API and database with no control at all. It is money, so it belongs behind fleet_management.financials. The server already strips it from the payload without that permission — so a control drawn unconditionally is an empty box, not a hidden one. Layout 2 draws it correctly; say if you would rather leave it out.

Pick a number. 2 is my recommendation. 1, 2 and 3 are three different answers to "twenty-one editable fields, none of which may hide". 4 is the recommendation at 375px, which is where the current card hurts most.
