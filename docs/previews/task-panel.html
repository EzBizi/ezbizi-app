Task panel: saving, and one form

Jose (11-16): "there doesnt seem to be a save button … all fields are different sizes, all pickers the same it's a mess." Today the panel does save each change (title on Enter, pickers at once), but it never says so, so it looks like nothing was kept. All three options use the same form: labels in one column (on top on a phone), every field the full width and one height (40), Timeline a compact "Nov 10 – Nov 16" box that opens the calendar only when tapped, in this order: Title, Status, Owner, Assigned, Due, Timeline, Text, then the board's other columns, Updates and Activity.

A · Saves by itself, and says so RECOMMENDED

Every change saves on its own: a picker the moment you choose, typing when you press Enter, leave the box, or stop for a second. The header says "Saving…" then "Saved ✓". If a save fails it says "Not saved", keeps what you typed, and offers Retry. Closing the panel saves anything still being typed. Shown with the Timeline tapped open.

B · A Save bar

Nothing is written until Save. A bar appears at the bottom once something changes ("2 unsaved changes · Cancel · Save"); closing with changes asks inside the panel. Familiar, but one more click per edit, and a status change from the board's table would still save at once, so the two places behave differently.

C · Pickers save at once, typing has a ✓

Status, people and dates save the moment they are chosen. While you type in a box, a small ✓ Save appears inside it (Enter does the same); closing saves it too. The header says "All saved" once nothing is waiting.
