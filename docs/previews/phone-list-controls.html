195 · Lists on a phone: the controls above the first row

UI pass 11-16. On a 375 px phone, Jobs, Customers and Customer Experience › Reviews each put 4–7 rows of controls above the first row. The list starts below 70% of the screen. The dashed orange line marks where the first row starts today. Desktop has room, so options 1–3 change little; the phone options 4–6 are the real choice. Recommended: 1 + 4. Every option keeps a search bar.

Today, at 375 (for comparison)

1 · Desktop: as today RECOMMENDED

Desktop has the room, so it keeps today's rows and every control in sight. Only the phone changes (option 4). Drawn as it is now, for comparison.

2 · Desktop: a filter rail on the left

Every filter in a left column, always open. It costs about 170 px of table width on every visit, and it doesn't fit 1366 px laptops with the sidebar open.

3 · Desktop: one toolbar line, the rest folded into ⋯

The Task Board approach: what fits stays on the line, everything else is in ⋯. It's very tidy, but on desktop it hides filters people use daily.

4 · Phone: search + Filters + ⋯, then one line of status chips RECOMMENDED

There are two control lines at most. Line 1 is search, Filters · n (opens a Filters page in place, as Leads already does since design 171) and ⋯ (Export, Import, Possible duplicates, Draft all, Fetch new). Line 2 is the status chips as one line that scrolls sideways; Customers has none. The count sentence moves into the group line. Customer Experience's rating card becomes one tappable line. The first row starts at about 30% of the screen instead of 70%.

5 · Phone: today's controls, scrolling away with the list

Nothing moves into a page: the controls scroll off as the list scrolls, and the search stays pinned. It looks the same as today at the top, so the first screen still shows almost no rows.

6 · Phone: search only, with a floating Filters pill

The fewest controls: a single search line, and a Filters pill floating above the bottom bar. It shows the most rows, but the pill covers a row and is a new pattern in the app.
