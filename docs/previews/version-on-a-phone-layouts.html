Where the version lives — pick one mobile and one desktop

Measured: BuildStamp is used in exactly two places — the foot of the sidebar and the sign-in screen. A phone has no sidebar and you are signed in, so there is nowhere. Its own docblock says it sits in “the two places somebody already is when they wonder whether the app has updated”, which stopped being true when the phone layout arrived. And a second gap while I was in there: the stamp is drawn if (expanded), so a collapsed desktop sidebar has nowhere either — 4, 5 and 6 are that.
