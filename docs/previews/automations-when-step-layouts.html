1 Sidebar icons on the left, compact cards, and a side panel that adds new information RECOMMENDED

  • On the left: the module names with the same icons as the sidebar, in the same groups and order.
    • Most used sits on top: the 8 events that happen most often here.
    • A rail entry with no events doesn't appear.
  • Each card shows a name, one line of description (the full text is on the right), and a footer: "72 in 30 days · 8 details · used by 2 rules".
  • Events that have never fired sort to the end, are greyed out, and say "Not raised yet".
  • The right panel no longer repeats the card. Its layout is drawn straight away with placeholders, so nothing jumps when the details finish loading. It shows:
    • the full description;
    • What you can use: the details in plain words (Email, Role, Expires on), not field names like expires_at;
    • Last 3 times it happened, with real values and when;
    • Rules already using it, each with a link;
    • Often paired with: one-click "Then" steps that other rules on this event use.
