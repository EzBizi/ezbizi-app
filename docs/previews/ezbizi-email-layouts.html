EzBizi emails · a branded frame for every email we send

Jose, 2026-10-01, with the overbooking warning: “can we make the overbooking report email more formatted, you know, ezbizi colors, etc, not just text, this should apply for any and all automations that send emails from ezbizi.”

Today: the overbooking warning is an automation email, and automation emails go out as plain text on purpose. An old decision kept business-written text out of EzBizi's styling so nobody would mistake a business's words for EzBizi's. Notifications and saved reports already use Laravel's mail layout, lightly tinted. Every option uses one frame for every email: automations (the overbooking warning included), saved reports, the weekly hours email, notifications, sign-in and invitation emails. Each also carries a plain-text copy for mail apps that want one. Business-written text keeps its safeguard: it is shown as text and never as HTML. Lists, bold and headings are allowed, and the business is named at the top and the bottom, so the same message can't pass as one from EzBizi. The warning itself becomes real structure: grouped by day, with the over-by amount and closed days marked, and a button to the page.

1The sign-in page’s navy band, a white card, colour only where it means something Recommended

The same navy gradient and Ez/Bizi wordmark as the sign-in and lock screens, so it is unmistakably ours. Two tiles count what needs attention. The days follow, each area with its count and a red “over” pill or a grey “closed day” pill, then the fully booked areas with their next opening. One button opens the page, and the footer says which automation sent it and where to change it.

What it touches (for whoever builds it): one layout for resources/views/vendor/mail/ (which notifications and saved reports already use), AutomationMessage moved from text-only to that layout with the text copy kept, and the overbooking job sending its days as structure rather than one block of text. Mail apps strip most CSS, so the real thing is built from tables with inline styles. Gmail, Outlook and Apple Mail are the three to check. In a mail app that blocks images the icon goes, but the wordmark is text, so the brand still shows.
