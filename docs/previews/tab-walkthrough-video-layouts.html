A walkthrough and a how-to video beside every tab's title

Jose, 2026-10-13: A1 Tools had a (?) and a ▶ next to each main tab's title. He wants both back in EzBizi. The walkthrough runs inside the app: it highlights each part of the tab, dims the rest and says what each part does. The video is a voiced how-to that we record for each tab. It is app-level, the same for every organization. The pictures use Scheduling, because its video is the first one being made. Every name and job here is invented.

The same in every option. A tab's walkthrough is a short list of steps, kept beside the tab's code. Each step names the control it points at, a title, a sentence or two and, optionally, "try it" (the tour waits until you do the thing). Each walkthrough carries a version. A step whose control you can't see is skipped, for example when your role lacks it or the module is off, so the tour never points at nothing. Whether you have seen a tab's walkthrough is stored for you on the server, so it follows you to the phone. When a release raises a tab's version, the tab offers only the new steps as What's new here. The video button shows only on a tab that has a video. EzBizi staff keep the list of which tab has which video, so a new video needs no release. Nothing opens as a dialog. Esc ends a walkthrough on a computer.
