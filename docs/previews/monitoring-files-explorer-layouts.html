Monitoring · Files · like Windows Explorer, behind the authenticator

Jose, 2026-10-12, via the Monitoring session: "have the files system require the authenticator code as well for extra security, and also if possible, can we make it sort of like windows explorer, where for example it shows previews of pictures, etc ? as well as quicklinks like desktop download, etc." Today it has a computer rail, a breadcrumb, and a plain list of names with chevrons. Downloads go to a tray.

What the server will give (Monitoring is building it).

  • An unlock with your authenticator code. It lasts 15 minutes and every file action extends it. When it lapses, the next action says "locked" and the code is asked for again in place, with no dialog.
  • Quick links (Desktop, Documents, Downloads, Pictures, Videos, Music), only the ones that exist on that computer. An older agent sends none.
  • Previews: the file is fetched when you select it, up to 5 MB, and the fetch is logged as a download, so there are no thumbnails for a whole folder. A thumbnail grid would need a new agent operation (later, if wanted).
  • Every entry has a name, folder or file, size and modified date.
Names, paths and files here are invented.

1Explorer's three panes, with the computer chosen at the top RECOMMENDED

Once a computer is chosen, the computer rail folds into a picker at the top ("Maya Lopez · FRONT-DESK-PC ▾"), which makes room for Explorer's layout. Quick access runs down the left (the links that exist, then the drives). The middle is a details list: Name, Modified, Size, sortable, with a type icon. The right is a preview pane: a picture shows itself, and anything else shows its icon, name, size, date and Download. A green "Unlocked · 14 min" in the toolbar shows how long is left, with Lock now.
