Dashboard · widgets you move and resize, grouped like Workiz's

Jose, 2026-10-05, with Workiz's dashboard beside ours: "it would be nice to be able to not only move around stuff but change the widget sizes between different available sizes, obviously smaller ones would show less information".

Three sizes in every option. Small is one figure with its change against the period before, like Workiz's tiles. Medium adds the chart and the few lines behind it. Large adds the breakdown with numbers and anything that needs someone. The figures come from each module; nothing is added up on the screen.

Money stays out, as you ruled on 2026-09-29: where Workiz shows sales and collected, these show counts (bookings, jobs done). Say so if that has changed and a widget may carry money. From the Dashboard module, for every option: each box's figures (label, value and the previous period's value, for the arrow) new, its 14-day or 24-hour series, its breakdown, its attention rows new, and a size beside presentation in PUT /dashboard/layout new.

1Sections like the menu, a four-column grid, a size switch on each widget Recommended

The dashboard reads like Workiz's: a row of Small tiles for today, then sections named and ordered like the menu (People, Work, Leads, Assets). Each section is a four-column grid: Small takes one column, Medium two, Large all four. Customize puts a size switch (S · M · L) and a handle on every widget: drag one within or across sections, switch its size, hide it, then Done. Why: three sizes and a grid of four make every arrangement line up by itself, and the sections keep a busy dashboard findable.

Data: the four above. Sections need nothing new: they are the menu's groups.

2A free grid: drag a widget's corner and it snaps to the next size

No sections: one six-column grid, as Grafana or a phone's home screen. Each widget's corner is a handle. Dragging it snaps to the size that fits: Small (two columns, one row), Medium (three columns, two rows), Large (six columns, two rows). More freedom, but also more ways to leave a gap.

Data: the four above. The layout also keeps each widget's place on the grid (column and row) new, not just its order.

3A row of tiles and two lanes: sizes from each widget's menu

The simplest of the three. Small widgets line up in the tile row at the top. Medium ones sit in two lanes below, and a Large one spans both lanes. Size, move up, move down and hide live in the ⋮ menu each widget already has, so there is no separate edit mode. Picking Small sends a widget up into the tile row.

Data: the four above, nothing else.
