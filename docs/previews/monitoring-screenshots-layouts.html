Desktop Monitoring — screenshots viewer, three layouts

One employee's periodic screen captures, in the Monitoring tab. Answer by number.

Real palette from theme.dart. The rule the whole viewer turns on (same honesty as the reachability column): a stale frame is never shown as if it were current — every capture carries its own time, the header says how long ago the last one was, and a device that isn't capturing (offline, no agent, web-only) says so instead of showing an old picture. Grey tiles are placeholder captures. No modal — enlarging opens a side panel. Resize narrow for 375px.
