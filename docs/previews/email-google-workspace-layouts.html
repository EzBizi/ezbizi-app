Email › Google Workspace: each Workspace's people and their signatures

Jose (2026-10-22): "a new tab in email, called Google Workspace … they would appear as cards which you can click on to set their settings individually like for example being able to set Signature, either per person or in bulk, using information from EzBizi if needed, by being able to link an email to a user as well." The server side is ready. Every name and address here is invented.

1 Workspace cards; opening one shows its people, a signature pane and a bulk bar RECOMMENDED

  • Cards: one per connected Workspace, showing the domain, where it's connected ("Brightside Home Services · company"), its people count and a signature status: Ready, "Needs a Google Admin step" or "No template yet". With only one Workspace, it opens straight away.
  • Inside a Workspace:
    • if signatures aren't ready, a yellow banner with the server's sentence;
    • Signature template at the top: an editor with placeholder chips (Name, First name, Title, Phone, Company…) and a live preview for a chosen person;
    • People table: tick box, name and address, title, EzBizi person, signature, last set;
    • EzBizi person is a picker. A match by email is offered with "Same email · Link"; a linked person fills Name, Title and Phone from EzBizi;
    • Signature is "Template", "Own" or "Not set". Suspended accounts are greyed out.
  • Ticking people shows a bar: "3 selected · Set signature". It applies each person's own signature, or the template, and reports each one ("2 set, 1 failed: …").
  • Clicking a person opens the side pane:
    • what Gmail has now next to what it will be;
    • "Use the template" or "Give them their own";
    • Set it now.
