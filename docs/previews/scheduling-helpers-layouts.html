Scheduling › Helpers: who has a helper, which day, which half

Brought over from A1 Tools' helper calendar for the A1 Leads takeover. Scheduling's server already has the helper roster and the bookings: whole day, morning or afternoon, with an optional job number and note. Every name here is invented.

The tab sits after Routing. You pick a branch and a month. You can book yourself a helper; somebody who can edit Scheduling can book one for anyone and change the roster. If a helper is already taken for that half, the screen says so ("That helper is already booked then"), and a whole day takes both halves.

1 A month calendar, as A1 draws it RECOMMENDED

  • Each day lists that day's bookings as coloured tags: blue for a whole day, green for the morning, yellow for the afternoon. A tag reads "helper → technician".
  • Click a day to open its panel on the right:
    • every helper, with Whole day / Morning / Afternoon and whether it's free;
    • Book, with the technician (yourself, unless you can edit Scheduling), a job number and a note;
    • Change and Remove on the bookings you're allowed to change.
  • Helpers in the header opens the roster: add a helper, rename one, or switch one off.
