Jose 11-10: "a sub tab where we can see all existing tags per account so if someone in the future changes a tag, we know about it and get a warning". Every Workiz account's tags against one approved standard, the drift highlighted, and a log of every rename, recolour, add and delete. Names are invented.

Server is done (Workiz): GET workiz/tags (accounts, rows with standard + per-account cell + differs, changes newest first, baseline_set) and POST workiz/tags/approve. Admins only.
