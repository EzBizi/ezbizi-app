Reports · every saved report

Jose, 2026-09-29, on the “Weekly work hours report” automation: “i should also be able to select which role gets reported or not or perhaps that's something that should show on the reports module, cause i see that it says on the which report weekly time report, so shouldn't i be able to see that existing report on reports?”

Today “Weekly Time Report” is a Work Hours saved report (Work Hours › Reports). It already names its roles, the people added or left out, and who it goes to. Reports lists only what its own Builder made, so it says “No reports built yet”. Each option answers both questions: where every report is seen, and how the automation step shows and changes who is reported. A Work Hours report shows only to people who may already see Work Hours reports.

1One library, every report, each edited where it lives Recommended

Reports › Reports lists every saved report, whichever module made it. Each row says what kind it is, who it covers, and when an automation sends it. A Work Hours report opens beside the list with its week of hours and who is in it. “Edit who is in it” opens the same editor Work Hours uses, right here, so it changes everywhere that report is used. The automation step says who the chosen report covers, and has the same button.

3Work hours reports move into Reports, and a rule can narrow one

Work Hours' Reports tab moves into Reports as a Work hours tab, the way Google Ads and Profit & Loss sit there. It has the same list, editor, preview and Send now. Work Hours keeps one line that points here. The automation step gets its own role ticks, starting from the report's: a rule can send the report for Remote Dispatcher only, while another sends it for everyone. Needs server work: the step gains a roles setting.
