1 The sentence, a checklist that names what's missing, a test run, then Turn on RECOMMENDED

  • Sentence: the whole rule in plain words.
    • A missing part is written in red as what's needed ("pick which detail to check"), not "not chosen yet". Clicking any part goes back to that step.
    • "Where it applies" names the actual place ("in Springfield · Brightside"), and only once.
  • Checklist: one line per step, each with ✓, ⚠ or ✕, a short reason, and Fix. While any line has ✕, Turn on is greyed out and says why.
  • Try it: runs the rule against a recent real event, or an example, without doing anything. It shows whether the conditions passed, and each step as "would send…" or "would update…" with the real values filled in.
  • At the bottom: Save switched off, then Turn on (the main button). After that it shows "On · runs on new events from now".
