Part A · Counts

1 Split the tab count, add "Other", caption the Result chips RECOMMENDED

  • Tab: "Calls · 296 in · 191 out", so it no longer looks like it disagrees with the tile.
  • Tile: "296 inbound calls" with a help line: "New + Existing + other lines".
  • Client chips: All 296 · New 125 · Existing 158 · Other 13, so the three add up to All.
  • Result chips: a caption names the client chip they count within, e.g. "Results within Existing (158)".

  • The people search bar (already in progress) works with it, so 34 people are set in one pass.
