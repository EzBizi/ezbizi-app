Settings lists

Settings, 11-04 ruling: every business value must be editable. A new Lists tab in Settings, beside Organization, Preferences, Integrations and Roles & permissions. Data comes from GET settings/lists; rows are added, changed and removed one at a time (POST, PATCH, DELETE). Every name is invented (Brightside).

1 Lists on the left, the chosen list in place on the right RECOMMENDED

  • Left: a search across list names, then the lists grouped by module, each with its row count. Opens on the first list.
  • Right: the list's help line, plus a Default values chip while nobody has edited it. A table with a drag handle and one cell per column: text, number, a tick box for yes/no.
  • Click a cell to edit it. It saves when you leave the cell (one PATCH per row). If the server refuses, its message shows under the row in red. A tick box saves at once.
  • ✕ removes the row at once, with an Undo snackbar; no dialog. + Add is the last row. Nobody types a key: the server makes it from the first text column.
