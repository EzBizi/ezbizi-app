Estimate Board

From Jose's Monday list: "New Estimate Board". The server is ready: GET /estimates filters by status and returns status_counts, and PATCH refuses an illegal move. So this is client work only. Production has 2,231 estimates: 40 draft, 42 sent, 243 accepted, 60 declined and 1,846 archived. Archived is three-quarters of them, so how the board handles it is the main choice. Every name and total here is invented.

1 List | Board toggle on Jobs › Estimates, Archived as a collapsed column RECOMMENDED

  • Where: the same tab, with the same search, "Company · Branch" picker and dates. A List | Board switch replaces the status chips; the column headers carry the same counts. Each person's choice is remembered.
  • Archived: a narrow amber strip at the right with its count. Clicking it opens it as a normal column, and a card can be dropped on it even while it's shut.
  • Drag: pick up a card and the columns it can't go to fade out, while the ones it can are outlined. A refused drop springs back with the server's reason. Clicking a card opens it in the SidePanel.
  • Long columns: 25 cards each, then "Show 25 more" (Accepted has 243).
