Ownership chart, process map, KPI report

Jose's Monday list: "Ownership Chart, Process Mapping, KPI Report", built as a screen inside EzBizi. Each part uses data EzBizi already holds, and amber dashed marks data that doesn't exist yet. Every name here is invented.

1 One "Company" module, three tabs RECOMMENDED

  • Ownership: a chart built from HR's roles and branches; each box names the area it owns.
  • Processes: Lead → Booking → Job → Payment → Review, each step with its owner and live counts.
  • KPIs: one table per role from Reports' figures, green at or above goal and red below.
  • Missing data, Ownership: no reports-to, manager or area-owner field. Until HR adds users.reports_to_user_id and an area owner per company or branch, the chart draws roles and branches only.
  • Missing data, KPIs: no goals per person or per role, and none for answer, booking or close rate; new ReportGoals keys with an optional role would cover it. Tech KPIs (done, canceled, canc%, tech-caused cancels, gross, share of gross, avg sale, deposits) arrive with b8a466693. Jobs a day is cheap to add; callbacks have no data at all.
  • Available now: branch close rate, canc%, avg sale, deposits and net margin; answer and booking rate per person.
