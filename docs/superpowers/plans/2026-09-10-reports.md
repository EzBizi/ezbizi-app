# Reports — backend implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A person with `reports.build` composes a report that reads across modules, saves it, and anyone granted `reports.view` runs it through the API and gets rows back — correctly scoped, capped, and audited.

**Architecture:** A hand-written map declares which tables are reportable, which columns they expose, how each is scoped, and which edges join them. A graph walk turns "start at jobs, show me the customer's name" into a join path along declared edges only. A runner builds the query from that path, re-applies tenant and view scope to **every** table on it, caps the rows, and writes an audit row. The saved report itself is an ordinary owned resource filed on the current view.

**Tech Stack:** Laravel 13, PHP 8.4, MySQL 8. No new dependencies — `AuthorizesCatalogPlace`, `PlaceInView`, `OwnedScope`, `RecordNumberGenerator` and `EventEmitter` already exist and are reused.

**Spec:** `docs/superpowers/specs/2026-09-10-reports-design.md` (committed `ed51de54`)

```php
<?php

namespace App\Support\Reports;

/**
 * The shortest declared route between two reportable tables.
 *
 * Breadth-first, so the path found is the fewest hops. That matters for more
 * than speed: a shorter path crosses fewer tables, and every table crossed is
 * one the runner must re-scope.
 *
 * There is no depth limit and that is deliberate — Jose asked for anything
 * joined to anything. The bound is not a number, it is the map: you can only
 * reach what somebody declared an edge to.
 */
final class RelationGraph
{
    /**
     * @return list<array{from: string, to: string, local: string, foreign: string}>|null
     */
    public static function pathBetween(string $from, string $to): ?array
    {
        if (ReportMap::get($from) === null || ReportMap::get($to) === null) {
            return null;
        }

        if ($from === $to) {
            return [];
        }

        // BFS. `$cameBy` doubles as the visited set, so a cycle in the map
        // terminates rather than looping — and maps do get cycles the moment
        // two tables declare edges to each other.
        $queue = [$from];
        $cameBy = [$from => null];

        while ($queue !== []) {
            $current = array_shift($queue);

            foreach (ReportMap::get($current)['relations'] as $edge) {
                $next = $edge['to'];

                if (array_key_exists($next, $cameBy)) {
                    continue;
                }

                $cameBy[$next] = [
                    'from'    => $current,
                    'to'      => $next,
                    'local'   => $edge['local'],
                    'foreign' => $edge['foreign'],
                ];

                if ($next === $to) {
                    return static::rebuild($cameBy, $to);
                }

                $queue[] = $next;
            }
        }

        return null;
    }

    /** @return list<array{from: string, to: string, local: string, foreign: string}> */
    private static function rebuild(array $cameBy, string $to): array
    {
        $path = [];

        for ($at = $to; $cameBy[$at] !== null; $at = $cameBy[$at]['from']) {
            array_unshift($path, $cameBy[$at]);
        }

        return $path;
    }
}
```

### Task 4: The runner

Where the scoping is either right or it is a leak. Every test in this task exists because of a specific way it could be wrong.

**Files:**
- Create: `app/Support/Reports/ReportRunner.php`
- Create: `app/Support/Reports/ReportResult.php`
- Test: `tests/Feature/Reports/ReportRunnerTest.php`

**Interfaces:**
- Consumes: `ReportMap`, `RelationGraph::pathBetween()`, `ViewScope::forUser()`, `TenantContext`.
- Produces: `ReportRunner::run(array $definition, User $user): ReportResult`. `ReportResult` is `readonly` with `public array $columns` (list of `array{key: string, label: string, type: string}`), `public array $rows` (list of associative arrays keyed by column key), `public bool $capped`, `public int $count`. `ReportRunner::ROW_CAP` is `int` 5000 and `ReportRunner::TIMEOUT_MS` is `int` 10000.

**The timeout has no test in this plan, deliberately.** Asserting it would mean manufacturing a query slow enough to trip ten seconds, which makes the suite slow and flaky to prove a MySQL setting works. The row cap *is* tested, because a fixture of 5001 rows is cheap. Say this out loud in the hand-over rather than letting a reviewer assume the timeout is covered — an untested guard is still worth having, but only if nobody believes it was checked.

```php
<?php

namespace App\Support\Reports;

use App\Models\User;
use App\Support\Scoping\ViewScope;
use App\Support\Tenancy\TenantContext;
use Illuminate\Support\Facades\DB;
use InvalidArgumentException;

/**
 * Turns a saved definition into rows (spec 2026-09-10).
 *
 * ── Everything is checked against the map, nothing against the request ──
 *
 * Table names, column names and join predicates come from ReportMap, never
 * from the definition. The definition only ever supplies KEYS INTO the map,
 * and a key that is not there throws. That is what keeps a report from
 * naming `password_reset_tokens`, and it is also why the errors below are
 * exceptions rather than filtered-out entries: a silently dropped column is
 * a smaller result and somebody shrugs, but a silently dropped FILTER is a
 * bigger one and nobody notices.
 *
 * ── Scope is applied per table, on every run ────────────────────
 *
 * Not once at the root. A report saved in the organization view and run from
 * a company view must come back smaller, so the filters go on at run time
 * from the CALLER's view, and they go on every table the path crosses.
 */
final class ReportRunner
{
    /**
     * ponytail: a flat cap, not a paginator. The builder is for questions
     * whose answer is a page or a chart; the day somebody genuinely needs
     * 200k rows the answer is an export job, not a bigger number here.
     */
    public const ROW_CAP = 5000;

    /**
     * A report that cannot answer in ten seconds is a report somebody should
     * narrow, not a query the database should keep grinding on. Without this
     * the builder's worst case is a table scan across several joined tables
     * holding a connection open — and the person who wrote it has already
     * closed the tab.
     */
    public const TIMEOUT_MS = 10000;

    private const OPERATORS = [
        'eq'       => '=',
        'ne'       => '!=',
        'lt'       => '<',
        'lte'      => '<=',
        'gt'       => '>',
        'gte'      => '>=',
        'contains' => 'like',
    ];

    public function __construct(private readonly TenantContext $tenant) {}

    public function run(array $definition, User $user): ReportResult
    {
        $root = $definition['root'] ?? '';
        $rootResource = ReportMap::get($root)
            ?? throw new InvalidArgumentException("There is no reportable resource called '{$root}'.");

        $view = ViewScope::forUser($user);
        $organizationId = $this->tenant->idOrFail();

        $query = DB::table($rootResource['table']);
        $joined = [$root => true];

        // Every resource the definition mentions, columns and filters alike.
        foreach ($this->resourcesUsed($definition) as $resourceKey) {
            if (isset($joined[$resourceKey])) {
                continue;
            }

            $path = RelationGraph::pathBetween($root, $resourceKey)
                ?? throw new InvalidArgumentException(
                    "A report starting at '{$root}' cannot reach '{$resourceKey}'."
                );

            foreach ($path as $hop) {
                if (isset($joined[$hop['to']])) {
                    continue;
                }

                $from = ReportMap::get($hop['from']);
                $to   = ReportMap::get($hop['to']);

                $query->leftJoin(
                    $to['table'],
                    $from['table'].'.'.$hop['local'],
                    '=',
                    $to['table'].'.'.$hop['foreign'],
                );

                $joined[$hop['to']] = true;
            }
        }

        // Scope EVERY joined table, including the root. A left join makes an
        // unscoped table produce extra columns rather than extra rows, which
        // is the quieter of the two failures and so the easier to miss.
        foreach (array_keys($joined) as $resourceKey) {
            $this->scope($query, ReportMap::get($resourceKey), $organizationId, $view);
        }

        $columns = [];
        foreach ($definition['columns'] ?? [] as $column) {
            $resource = $this->resourceFor($column);
            $declared = $this->columnFor($resource, $column);
            $key = $column['resource'].'.'.$column['column'];

            $query->addSelect(
                DB::raw(
                    $this->quote($resource['table']).'.'.$this->quote($column['column'])
                    .' as '.$this->quote($key)
                )
            );

            $columns[] = ['key' => $key, 'label' => $declared['label'], 'type' => $declared['type']];
        }

        if ($columns === []) {
            throw new InvalidArgumentException('A report needs at least one column.');
        }

        foreach ($definition['filters'] ?? [] as $filter) {
            $resource = $this->resourceFor($filter);
            $this->columnFor($resource, $filter);

            $operator = self::OPERATORS[$filter['op'] ?? '']
                ?? throw new InvalidArgumentException(
                    "'".($filter['op'] ?? '')."' is not a filter this report can use."
                );

            $value = $filter['value'] ?? null;

            $query->where(
                $resource['table'].'.'.$filter['column'],
                $operator,
                $operator === 'like' ? '%'.$value.'%' : $value,
            );
        }

        // One more than the cap, so "there were more" is a fact rather than a
        // guess — a result of exactly ROW_CAP is ambiguous otherwise.
        $rows = $this->withTimeout(fn () => $query->limit(self::ROW_CAP + 1)->get()
            ->map(fn ($row) => (array) $row)->all());

        $capped = count($rows) > self::ROW_CAP;

        if ($capped) {
            $rows = array_slice($rows, 0, self::ROW_CAP);
        }

        return new ReportResult($columns, $rows, $capped, count($rows));
    }

    /** @return list<string> */
    private function resourcesUsed(array $definition): array
    {
        $keys = [];

        foreach (array_merge($definition['columns'] ?? [], $definition['filters'] ?? []) as $item) {
            $keys[] = $item['resource'] ?? '';
        }

        return array_values(array_unique($keys));
    }

    private function resourceFor(array $item): array
    {
        $key = $item['resource'] ?? '';

        return ReportMap::get($key)
            ?? throw new InvalidArgumentException("There is no reportable resource called '{$key}'.");
    }

    private function columnFor(array $resource, array $item): array
    {
        $column = $item['column'] ?? '';

        return $resource['columns'][$column]
            ?? throw new InvalidArgumentException(
                "'{$resource['label']}' does not report a column called '{$column}'."
            );
    }

    private function scope(mixed $query, array $resource, string $organizationId, ViewScope $view): void
    {
        $table = $resource['table'];

        $query->where($table.'.organization_id', $organizationId);

        if ($resource['place'] === 'none' || $resource['place'] === 'organization') {
            return;
        }

        // The organization view sees the whole tenant, so it adds nothing.
        if ($view->isOrganization()) {
            return;
        }

        // ViewScope answers in PLURALS — `companyIds()`, not `companyId()` —
        // because a view can cover several places. Reaching for the singular
        // is the mistake to avoid here: there is no such method, and writing
        // one would flatten a multi-company view down to its first entry.
        $companyIds = $view->companyIds();

        if ($companyIds !== []) {
            $query->whereIn($table.'.company_id', $companyIds);
        }

        if ($resource['place'] === 'franchise') {
            $franchiseIds = $view->franchiseIds();

            if ($franchiseIds !== []) {
                $query->whereIn($table.'.franchise_id', $franchiseIds);
            }
        }
    }

    /**
     * ponytail: a session variable rather than a per-statement hint, because
     * the hint has to sit immediately after the SELECT keyword and Laravel's
     * builder gives no clean seam for that. The ceiling: it is MySQL-only and
     * applies to reads alone, which is all this class runs. If the query
     * builder ever grows a hint API, move it there and drop the finally.
     */
    private function withTimeout(callable $fn): mixed
    {
        DB::statement('SET SESSION max_execution_time = '.self::TIMEOUT_MS);

        try {
            return $fn();
        } finally {
            // Connections are pooled, so leaving it set would silently cap
            // every later query on this connection — including writes made by
            // whatever handles the next request.
            DB::statement('SET SESSION max_execution_time = 0');
        }
    }

    private function quote(string $identifier): string
    {
        // The identifier always comes from the map, never from the request —
        // but quoting is free and the day somebody widens the map is the day
        // that stops being obvious.
        return '`'.str_replace('`', '', $identifier).'`';
    }
}
```

```php
<?php

namespace App\Http\Controllers\Api;

use App\Models\Company;
use App\Models\Franchise;
use App\Models\SavedReport;
use App\Support\Audit\AuditLogger;
use App\Support\Reports\ReportMap;
use App\Support\Reports\ReportRunner;
use App\Support\Scoping\PlaceInView;
use App\Support\Scoping\ViewScope;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;
use Illuminate\Validation\ValidationException;
use Symfony\Component\HttpFoundation\Response;

/**
 * Saved reports — list, build, run (spec 2026-09-10).
 *
 * A definition is validated against ReportMap at SAVE as well as at run.
 * Both, not either: validating only at save lets a map shrink out from under
 * a stored report, and validating only at run means the builder cheerfully
 * saves something that can never work.
 */
class ReportsController extends Controller
{
    public function __construct(
        private readonly ReportRunner $runner,
        private readonly AuditLogger $audit,
    ) {}

    public function fields(Request $request): JsonResponse
    {
        $this->authorize('viewAny', SavedReport::class);

        $out = [];

        foreach (ReportMap::all() as $key => $resource) {
            if (! $request->user()->hasPermission($resource['permission'])) {
                continue;   // you cannot report on a module you cannot open
            }

            $out[$key] = [
                'label'     => $resource['label'],
                'columns'   => $resource['columns'],
                'relations' => array_map(
                    fn (array $edge) => ['to' => $edge['to']],
                    $resource['relations'],
                ),
            ];
        }

        return response()->json(['data' => $out]);
    }

    public function index(Request $request): JsonResponse
    {
        $this->authorize('viewAny', SavedReport::class);

        $view = ViewScope::forUser($request->user());

        $reports = SavedReport::query()
            ->unless($view->isOrganization(), function ($q) use ($view) {
                $companyIds = $view->companyIds();

                if ($companyIds !== []) {
                    $q->whereIn('company_id', $companyIds);
                }
            })
            ->orderBy('name')
            ->get();

        return response()->json(['data' => $reports->map($this->present(...))->all()]);
    }

    public function store(Request $request): JsonResponse
    {
        $data = $this->validated($request);

        $company = $data['company_id'] === null ? null : Company::findOrFail($data['company_id']);
        $franchise = $data['franchise_id'] === null ? null : Franchise::findOrFail($data['franchise_id']);

        $this->authorize('create', [SavedReport::class, $company, $franchise]);

        PlaceInView::assert($request->user(), $company, $franchise, 'report');

        $report = SavedReport::create($data);

        return response()->json(['data' => $this->present($report)], Response::HTTP_CREATED);
    }

    public function show(string $id): JsonResponse
    {
        $report = SavedReport::findOrFail($id);
        $this->authorize('view', $report);

        return response()->json(['data' => $this->present($report)]);
    }

    public function update(Request $request, string $id): JsonResponse
    {
        $report = SavedReport::findOrFail($id);
        $this->authorize('update', $report);

        $report->update($this->validated($request, $report));

        return response()->json(['data' => $this->present($report->fresh())]);
    }

    public function destroy(string $id): JsonResponse
    {
        $report = SavedReport::findOrFail($id);
        $this->authorize('delete', $report);

        $report->delete();

        return response()->json([], Response::HTTP_NO_CONTENT);
    }

    public function run(Request $request, string $id): JsonResponse
    {
        $report = SavedReport::findOrFail($id);
        $this->authorize('view', $report);

        $result = $this->runner->run($report->definition, $request->user());

        // Reading widely is this screen's normal case, so a run is written
        // down. Five modules in this app write no audit rows at all; a report
        // run is precisely the event an audit trail exists for.
        //
        // Named arguments because `log()` takes $changes third and $metadata
        // fourth — a run changes nothing, so positional args would file the
        // row count as a field change.
        $this->audit->log(
            action: 'report.run',
            target: $report,
            metadata: [
                'name'      => $report->name,
                'row_count' => $result->count,
                'capped'    => $result->capped,
            ],
        );

        return response()->json(['data' => [
            'columns' => $result->columns,
            'rows'    => $result->rows,
            'capped'  => $result->capped,
            'count'   => $result->count,
            'cap'     => ReportRunner::ROW_CAP,
        ]]);
    }

    private function validated(Request $request, ?SavedReport $existing = null): array
    {
        $data = $request->validate([
            'company_id'   => ['nullable', 'uuid'],
            'franchise_id' => ['nullable', 'uuid'],
            'name'         => ['required', 'string', 'max:120'],
            'description'  => ['nullable', 'string', 'max:2000'],
            'definition'   => ['required', 'array'],
        ]);

        $data['company_id'] ??= null;
        $data['franchise_id'] ??= null;

        // Save-time validation is a dry run of the real thing rather than a
        // second copy of its rules — a second copy is what drifts.
        try {
            $this->runner->run($data['definition'], $request->user());
        } catch (\InvalidArgumentException $e) {
            throw ValidationException::withMessages(['definition' => $e->getMessage()]);
        }

        return $data;
    }

    private function present(SavedReport $report): array
    {
        return [
            'id'           => $report->id,
            'name'         => $report->name,
            'description'  => $report->description,
            'company_id'   => $report->company_id,
            'franchise_id' => $report->franchise_id,
            'definition'   => $report->definition,
        ];
    }
}
```

```php
    automationActions: [
        new ActionDefinition(
            key: 'report.send',
            label: 'Email a report',
            description: 'Runs a saved report and emails the result to the '
                .'people you name. The report is run with this rule\'s own '
                .'scope, so a rule belonging to one franchise cannot mail a '
                .'report covering the whole organization.',

             * Spelled out, and it is load-bearing. ActionDefinition derives
             * the execution type as everything after the FIRST dot, so
             * `report.send` left alone becomes the bare word `send` — which
             * the next module declaring `x.send` would also claim, silently.

             * rather than a present one. Note the asymmetry that makes it
             * worth doing: the constructor validates the dotted shape only

             * The report and the recipients come from the rule's own
             * configuration, not from whatever record the event was about —
             * "email the weekly job report when a month closes" has no
```

```php
<?php

namespace App\Support\Dashboard\Glances;

use App\Models\SavedReport;
use App\Models\User;
use App\Support\Dashboard\DashboardPeriod;
use App\Support\Dashboard\DescribedGlance;
use App\Support\Dashboard\GlancePayload;
use App\Support\Scoping\ViewScope;
use App\Support\Tenancy\TenantContext;

/**
 * Reports box: how many saved reports this view can run.
 *
 * A snapshot rather than a period series — a report either exists or it does
 * not, and "reports created this month" is a question nobody asks.
 */
final class ReportsGlance extends DescribedGlance
{
    protected const KEY = 'reports';
    protected const LABEL = 'Reports';
    protected const PERMISSION = 'reports.view';
    protected const PRESENTATIONS = ['text'];
    protected const DEFAULT_PRESENTATION = 'text';
    protected const SNAPSHOT = true;

    public function resolve(User $user, DashboardPeriod $period, array $options): GlancePayload
    {
        return app(TenantContext::class)->run($user->organization, function () use ($user) {
            $view = ViewScope::forUser($user);

            $total = SavedReport::query()
                ->unless($view->isOrganization(), function ($q) use ($view) {
                    $companyIds = $view->companyIds();

                    if ($companyIds !== []) {
                        $q->whereIn('company_id', $companyIds);
                    }
                })
                ->count();

            if ($total === 0) {
                return new GlancePayload(
                    key: $this->key(),
                    label: $this->label(),
                    presentation: $this->defaultPresentation(),
                    allowedPresentations: $this->allowedPresentations(),
                    snapshot: $this->snapshot(),
                    comingSoon: false,
                    options: [],
                    data: [
                        'empty' => true,
                        // One sentence, because `empty: true` renders exactly
                        // one and silently drops any others.
                        'sentence' => 'No reports built yet.',
                    ],
                );
            }

            return new GlancePayload(
                key: $this->key(),
                label: $this->label(),
                presentation: $this->defaultPresentation(),
                allowedPresentations: $this->allowedPresentations(),
                snapshot: $this->snapshot(),
                comingSoon: false,
                options: [],
                data: [
                    'empty' => false,
                    'sentences' => [
                        $total === 1 ? '1 report saved.' : "{$total} reports saved.",
                    ],
                ],
            );
        });
    }
}
```

Two things about this that are not style. **The key is `reports`, matching the module key exactly** — `GlanceRegistryTest` compares sidebar modules and glance keys as a sorted-set equality, so `reports.saved` would fail the gate on both sides at once. And **`empty: true` renders one sentence and drops the rest**, which is why the zero case carries `sentence` (singular) while the populated case carries `sentences`; a second sentence added to the empty branch would vanish with no error.

The `DescribedGlance` base and `GlancePayload` belong to the Dashboard session (`local_0417a3f0-f2bd-40a3-93d0-e8ea69d32c35`). This file is yours; those two are not — if the payload shape has moved, read theirs and follow it rather than adapting it here.
